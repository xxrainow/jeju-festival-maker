# 오류·안내 문구와 대처, 알려진 한계

큰따옴표("") 안 문장은 화면에 나오는 문장 그대로입니다. 중괄호({ })는 상황마다 바뀌는 부분입니다.

## 1. 설치·실행

| 증상 | 원인 | 대처 |
|---|---|---|
| `uv: command not found` / `'uv'은(는) … 인식되지 않습니다` | uv 설치 직후 터미널이 새 경로를 모름 | 터미널(PowerShell)을 닫았다가 다시 엽니다 |
| `uv sync --locked`에서 내려받기 오류 | 인터넷 연결 없음, 회사·센터 방화벽 | 인터넷이 되는 곳에서 설치합니다. 설치 뒤 확인 도구는 인터넷 없이 돌아갑니다 |
| 브라우저가 안 열림 | 자동 열기 실패 | 주소창에 http://127.0.0.1:8501 을 입력합니다 |
| `Port 8501 is already in use` | 이미 실행 중인 창이 있음 | 먼저 실행한 터미널에서 Ctrl + C로 끄거나, `uv run streamlit run streamlit_app.py --server.port 8502`로 실행합니다 |
| 설정 패널에 "설정 필요"가 계속 나옴 | `.env`가 없거나, `LLM_PROVIDER`가 `gemini`가 아니거나, 키가 비어 있음 | `.env` 파일 이름(앞에 점, 확장자 없음)과 내용을 확인하고 프로그램을 다시 실행합니다 ([install.md](install.md) 2절) |

## 2. AI 연결

| 화면 문구 | 원인 | 대처 |
|---|---|---|
| "AI 설정이 없어요. 아래 칸에 조건을 직접 입력해주세요." | 키가 없음 (① 한 문장 정리) | 조건 칸에 직접 입력해도 됩니다. AI를 쓰려면 키를 넣습니다 |
| "⚠️ 예시 카드예요" + "AI를 쓸 수 없어 입력과 상관없는 예시 카드예요. 입력한 지역·계절·재료가 반영되지 않았어요." + "이유: AI 키가 설정되지 않았어요." | 키가 없어 애월 감귤 예시 카드를 보여줌 | 키를 넣고 ①에서 다시 **아이디어 보기** |
| 같은 경고 + "이유: 오늘 AI 사용 한도를 넘었어요. 잠시 뒤 다시 해보세요." | 무료 사용량 초과 (HTTP 429) | 시간이 지나 다시 하거나, 사용량이 넉넉한 키를 씁니다 |
| 같은 경고 + "이유: AI 서버에 연결하지 못했어요." | 인터넷 끊김, 응답 시간 초과, Google 서버 오류(5xx) | 인터넷을 확인하고 다시 합니다. 서버 오류는 잠시 뒤 다시 합니다 |
| "아이디어 생성 중 AI 호출에 실패했어요. API 키가 올바르지 않아요. .env의 LLM_API_KEY를 확인해주세요. (HTTP 401)" | 키를 잘못 붙여 넣음 | 키를 다시 복사해 넣습니다 (앞뒤 빈칸·따옴표 없이) |
| "… API 키에 권한이 없어요. Google AI Studio에서 키와 프로젝트를 확인해주세요. (HTTP 403)" | 키의 프로젝트에 Gemini API 권한이 없음 | AI Studio에서 새 키를 만듭니다 |
| "… 모델을 찾지 못했어요. .env의 LLM_MODEL을 확인해주세요. (HTTP 404)" / "… 요청 형식이 맞지 않아요. 모델 이름(LLM_MODEL)을 확인해주세요. (HTTP 400)" | `LLM_MODEL`에 없는 모델 이름 | `LLM_MODEL=`을 비워 기본 모델을 씁니다 |
| "AI 응답을 읽지 못했어요. 아래 칸에 조건을 직접 입력해주세요." | AI가 정해진 형식으로 답하지 않음 (2번 시도) | 한 번 더 누르거나 칸에 직접 입력합니다 |

| "⚠️ 이 지역은 자료가 적어 결과가 불안정할 수 있어요. …" | 그 동네의 와이파이 장소가 5곳 미만, 날씨 지점이 20km 넘게 떨어짐, 사용자 수가 적음 (지금은 추자면) | 결과를 참고로만 봅니다 |

## 5. 확인 결과의 "데이터 대기"와 "가상 데이터"

### 데이터 대기

판정에 필요한 자료가 없으면 실패가 아니라 "데이터 대기"로 둡니다. **이대로 진행**은 막지 않습니다.

| 화면 문구 | 원인 |
|---|---|
| "지역이 없어 외지인 방문과 날씨를 확인하지 못했어요." (시기) / "지역이 없어 후보 장소를 찾지 않았어요." (장소) / "지역이 없어 동네와 제주 평균을 비교하지 못했어요." (대상) | 지역을 "(제주 전역)"으로 둠 |
| "대상이 입력되지 않아 확인하지 않았어요." | 대상 칸이 비어 있음 |
| "대상 '{대상}'을(를) 연령대로 바꾸지 못했어요. 가족, 청소년, 청년, 중장년, 어르신, 20~30대, 여성 같은 말로 입력해 주세요." | "관광객"처럼 연령대로 바꿀 수 없는 말 |
| "와이파이 자료에 60대 이상이 거의 집계되지 않아 확인할 수 없어요." (10대 미만도 같음) | 어르신·영유아 대상. 원자료가 2020-07 이후 이 연령대를 거의 세지 않음 ([data-spec.md](data-spec.md)) |
| "정체: 데이터 대기" | 교통량 자료 또는 후보 장소 좌표가 없음 |
| "시기 확인용 표가 아직 없어요. 관리자에게 표 만들기를 요청해 주세요." 같은 "표가 아직 없어요" | 가공본 파일이 빠짐. 제출본에는 모두 들어 있어 보통은 나오지 않습니다 |

### 가상 데이터 표시

센터 지정 데이터 중 아직 실데이터를 받지 못한 것은 **명세서 구조대로 만든 가상 데이터**로 계산하고 표시합니다.

| 화면 표시 | 뜻 |
|---|---|
| 확인 카드의 "🧪 가상 데이터 포함" | 그 확인 결과에 가상 데이터가 쓰였음 (지금은 위험 확인의 주거 밀집·정체) |
| 숫자 끝의 "(가상 데이터)" | 그 숫자가 가상 데이터에서 나옴 (행사 시간대·야간 귀가 정류소 승차, 야간 거주인구, 정체, 4-11 참고 비중) |
| "주거 밀집은 4-11 가상 데이터로 계산했어요. 실제 거주인구가 아니에요." 등 (주의할 점) | 같은 내용의 경고 |
| "🧪 가상 데이터가 섞인 확인 결과로 만든 기획서예요." / "🧪 가상 데이터가 섞인 기획서로 만든 홍보물이에요." | 기획서·홍보물에 가상 데이터 결과가 섞였음 |

- 행사 시간대 버스 승차와 대상의 4-11 비중은 **참고로만 보여주고 판정에는 쓰지 않습니다.**
- 실데이터로 바꾸는 방법은 [data-spec.md](data-spec.md) 3절에 있습니다.

## 6. 알려진 한계

**데이터**
- 외지인 방문은 사람 수가 아니라 **와이파이 관광 목적 데이터 사용량**으로 대신 봅니다. 4-11 유동인구 실데이터가 1년 이상 쌓이면 바꿀 수 있게 만들었습니다.
- 와이파이 사용자 연령대는 2020-07부터 60대 이상·10대 미만이 거의 집계되지 않습니다(50대로 합쳐진 것으로 보임).
  - 그래서 어르신·영유아 대상은 판정하지 않고, 가족은 30·40대로만 봅니다.
  - 50대 비중에는 60대 이상이 섞여 있을 수 있습니다.
- 날씨는 동네에서 가장 가까운 기상청 지점(제주·고산·성산·서귀포) 4곳의 2017~2025년 9년 평균입니다. 동네 안 날씨와 다를 수 있습니다. 추자면은 지점까지 53km입니다.
- 버스 정류소 이용 인원은 이름 단위라, 같은 이름의 양방향 정류소가 합쳐져 있습니다.
- 문체부 축제 방문객 수는 지자체 자체 보고라 참고로만 보여주고 점수에 쓰지 않습니다. 예산 비교는 2026 개최 계획 기준이고, 1일 축제 자료가 없어 2일 이상 축제와 비교합니다.
- 제주 재료 사전은 35개입니다. 고등어·당근·녹차·보리처럼 없는 소재는 다른 재료로 추천됩니다.
- 제주 축제 목록(문체부 2026 계획 + 전국문화축제표준데이터)은 제주시 축제가 일부 빠져 있을 수 있습니다. 날짜 미확인 축제는 "직접 확인" 경고만 붙입니다.

**기능**
- 한 문장의 "11~12월" 같은 **달 정보는 저장되지 않고 계절만 남습니다.** 카드의 추천 월은 계절·제철로 정해집니다.
- 지역은 행정동·읍면 43곳 단위입니다. 리·마을 단위로는 고를 수 없습니다.
- 대상 비중이 낮아도 실패로 두지 않고 "홍보 대상을 넓히거나 장소를 바꿔보세요" 경고만 줍니다. 대상은 사용자가 정한 값이라서입니다.
- AI가 쓴 카드·기획서·SNS 글은 규칙 검사(근거 없는 숫자, 정하지 않은 장소, 없는 프로그램, 어색한 문장)를 거칩니다. 그래도 문장 자연스러움은 사람이 마지막에 확인해야 합니다.
- 기획서의 프로그램은 "제안"입니다. 형식이 야간·빛·드론이면 작은 예산에도 드론 쇼를 제안할 수 있습니다. 비용은 확인하지 않습니다.
- 행사장 대관, 숙박, 주최·주관, 항목별 예산은 확인하지 않고 "미확인"으로 둡니다.
- 방문객 수와 경제효과는 예측하지 않습니다. 규모 확인의 "대략 몇 명 규모"는 비슷한 축제의 1인당 비용으로 거꾸로 계산한 범위입니다.
- 홍보물은 시안입니다. SNS 게시, 광고, 대관은 하지 않습니다.
- 화면은 한 번에 한 사람이 쓰는 것을 전제로 합니다. 새로고침하면 진행 중인 내용이 처음으로 돌아갈 수 있습니다. 기획서·포스터 파일은 `outputs/`에 남습니다.
