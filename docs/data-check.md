## 2. 데이터별 점검 결과

### 2-1. 버스정류소 이용 인원 (핵심)

- 컬럼: `base_date`, `station_name`, `user_type`, `user_count`
- 정류소명 2,806개, 이용자 유형 9개 (일반, 경로, 청소년, 장애 일반, 장애 동반, 어린이, 유공 일반, 기타, 유공 동반)
- **정류소명 안에 쉼표가 따옴표 없이 들어 있음.** 예: `제주국제공항(대정,화순,일주서로)`. 전체의 약 0.65%(103,306행)가 열 개수 5~6개로 깨짐. 일반 CSV 읽기로는 오류가 나거나 공항 정류소가 빠짐
  - 처리: 첫 칸은 날짜, 마지막 두 칸은 유형과 인원, 그 사이 전체를 정류소명으로 읽음
- **2022-08-12 ~ 2022-11-23 데이터 없음.** 2022년은 260일만 존재. 2022-08-11, 2022-11-24~27, 2021-12-23은 하루 이용자가 17~305명으로 비정상
  - 처리: 결측 기간은 결과에 표시. 비정상일은 날짜를 직접 고르지 않고 규칙으로 판정
  - 이상일 규칙: 하루 합계가 **같은 달 같은 요일 하루 합계 중앙값의 20% 미만**인 날. 분석에서 기본 제외하고 제외 날짜 목록을 결과와 함께 반환. 기준값(20%)은 조정 가능
  - 20% 기준 결과: 15일 (2020-12-15, 2021-04-10, 2021-12-23, 2022-01-03, 2022-01-25, 2022-07-09, 2022-07-15, 2022-08-11, 2022-12-05, 2022-12-06, 2022-12-28, 2024-06-20, 2024-07-07, 2024-07-08, 2025-03-19). 10%는 15일, 30%는 37일, 50%는 144일
  - 한계: 2022-08, 2022-11은 같은 요일 자료가 1~2일뿐이라 중앙값이 불안정. 특히 2022-11-24~29(하루 85~3,796명)는 요일마다 하루씩이라 걸러지지 않음. 결과 안내 문구에 함께 표시
- **같은 정류소의 이름이 시기별로 바뀜.** 예: `제주국제공항4(대정,화순,일주서로)`(~2024-10-06) → `제주국제공항4(대정화순일주서로)`(2024-10-07~). 2019-12-10에도 번호 체계 변경
  - 처리: 공백, 쉼표, 괄호 안 구두점을 제거한 정규화 이름을 따로 만들어 기간 연결
- `(구)`가 붙은 폐지 정류소 7개 존재. 제외하지 않고 그대로 사용

### 2-2. 와이파이 장소별 사용자 현황 (핵심)

- 컬럼: `base_year_month`, `sex`, `age_range`, `wifi_place_name`, `user_count`
- 장소명 3,779개, 연령대 7개 (10대 미만 ~ 60대 이상)
- **2020-09 이전과 이후의 집계 방식이 다름.** 2018~2019년 합계가 연 1.3억~2억 명인데 2021년 이후는 연 5천만 명 수준
  - 처리: **2020-10 이후 데이터만 사용**
- 2020-10 이후에도 `#1` 같은 AP 번호가 붙은 장소명 16개 남아 있음. 장소 단위로 합칠 때 번호 제거
- `user_count` 값 오류 1건: `1012``(201805, 버스정류소_삼아아파트[남]). 숫자 외 문자 제거 후 변환
- 10 미만 값 178,300행(약 12%). 공개 데이터라 반출 기준 대상은 아니지만, 작은 장소는 변동이 커서 순위 비교 시 주의
- 월별 패턴(2024~2025): 4~7월 최고, 11~2월 최저. 비수기 판단 근거로 활용 가능

### 2-3. 와이파이 장소별 방문자별 사용량 (보조, 활용 가치 확인됨)

- 컬럼: `base_year_month`, `quarter`, `sex`, `age_range`, `visit_type`, `wifi_place_name`, `use_amount`
- **`visit_type`에 실제 값이 있음:** 거주, 관광, 업무, 기타, 국제회의 및 인센티브 투어. 미리보기에서 비어 보였던 것은 2020-09 이전 행(466,225행)이 빈 값이기 때문
- `use_amount`는 사람 수가 아니라 데이터 사용량
  - 활용: 장소별 **관광 목적 사용량 비중**을 관광객 비중 대용 지표로 사용. 사람 수로 해석하지 않음
- 2020-10 ~ 2020-11에 `visit_type` 칸에 `"NULL"` 문자열 154행. 방문유형 결측으로 처리

### 2-4. 제주도 방문 내국인 유동인구 추이 (보조)

- 컬럼: `base_year_month`, `sex`, `age_range`, `time_range`, `visit_population_count`
- **지역 구분 없는 제주 전체 합계.** 장소 비교에는 사용 불가, 월별·시간대별 흐름에만 사용
- **같은 칸이 2줄로 중복된 행 존재 (합산 필요)**
  - 2022-06 이전: `70대 이상`이 2줄 (70대, 80대 이상이 같은 이름으로 들어간 것으로 추정)
  - 2022-07 이후: `10대`~`60대`가 2줄 (5세 단위를 10세 단위로 바꾼 것으로 추정)
  - 처리: (년월, 성별, 연령대, 시간대) 기준으로 합산
- **시간 표기 변경:** 2022-06까지 `24시`, 2022-07부터 `00시`. 같은 시간대로 통일
- **2023년부터 연간 합계가 약 40% 감소** (2.8십억 → 1.7십억). 실제 감소보다 집계 방식 변경 가능성이 큼
  - 처리: 연도 간 비교 금지. 같은 해 안의 월별 비중으로만 사용
- 2025-04에서 끝나고, 센터 4-11(내국인 유동인구 읍면동 v02)이 2025-05부터 시작. 센터 데이터 연결 시 이어지는 구조로 설명 가능

### 2-5. 전국 문화축제 표준데이터 (핵심)

- 1행이 비어 있고 2행이 헤더. `header=1`로 읽어야 함
- 제주 축제 50건 (주소, 주최·주관기관에 제주 또는 서귀포 포함 기준). 좌표 없는 행 2건
- **서귀포시 축제가 대부분이고 제주시는 소수.** 제주시 대표 축제 일부가 빠졌을 가능성. 완전한 목록으로 보지 않음
- 같은 축제 중복 등록: 한라산 청정 고사리 축제 2건, 하영 빛나는 서귀포 2건, 새연교 공연 2건, 제주메밀축제 2건
  - 모두 서귀포시 등록분을 제주특별자치도가 다시 등록한 것. 이름 표기가 달라 직접 확인한 목록으로 도청 등록분을 `is_duplicate` 표시 (삭제하지 않음)
- 시기 분포: 3~6월 집중, **11~12월은 개최 축제 거의 없음**. 기존 축제와 겹치지 않는 시기 근거로 활용 가능
- 축제내용 칸에 프로그램 구성이 있어 개발자 A의 사례 기본 목록으로도 활용 가능

### 2-6. 시내버스 노선 현황 (보조)

- CP949 인코딩. 읽을 때 `encoding="cp949"` 지정 필요
- 운행구간이 `하귀(번대동)-외도초-...` 같은 글자로만 되어 있어 동네 단위 연결이 어려움. 노선 수와 배차간격 참고용으로만 사용

## 3. 위치 연결 계획

기준 단위는 **행정동 43개** (센터 4-11과 같은 단위).

| 데이터 | 위치 정보 | 행정동 연결 방법 |
|---|---|---|
| 버스 이용 인원 | 정류소명 | 버스 정류소 기본 정보(API)의 `stationAddress` |
| 와이파이 사용자·사용량 | 장소명 | 공공와이파이 AP 정보(API)의 `addressDong` |
| 관광지 유입자 | 관광지명 | AP 정보에서 같은 이름 찾기, 안 되면 직접 매핑 |
| 관광 숙박업 | 주소 | 주소에서 읍면동 추출 |
| 문화축제 | 주소, 좌표 | 주소에서 읍면동 추출 |

- 리 단위 주소(예: 성산읍 고성리)는 앞의 읍·면으로 묶음
- 시내 법정동(예: 삼도이동)은 행정동 매핑표 필요
- 정류소 기본 정보에서 확인한 문제: 같은 이름 정류소가 다른 동에 있음(예: `(구)삼양검문소` 삼양동/조천읍), 주소가 빈 정류소 있음(좌표로 보완), 주소 끝 공백 있음
- **연결 후 반드시 매칭률 확인.** 전체 대비 연결 비율과, 연결 안 된 항목이 특정 지역에 몰렸는지 확인
- MVP는 후보 지역 3곳 기준으로 매핑표를 먼저 만들고, 이후 확장

## 4. 분석 기본 기간

`analytics/periods.py`에 정의. 기간은 `analysis_period(start_month, end_month)`로 바꿔 쓸 수 있음.

| 용도 | 기본 기간 | 이유 |
|---|---|---|
| 여러 데이터 비교 분석 | 2023-01 ~ 2024-12 | 모든 데이터가 겹치는 기간 (관광지 유입자 2022~2024, 유동인구 ~2025-04) |
| 단일 데이터 후보지 분석 | 2023-01 ~ 2025-10 | 2022년 버스 이상일 판정 불안정 구간(2022-08, 2022-11) 제외 |
| 최근 패턴 확인 | 2025-01 ~ 2025-10 | 비교 분석과 섞지 않고 따로 표시 |

- 버스 이상일 규칙(20%)은 그대로 유지. 2023년 이후 기간에는 판정이 불안정한 달이 없음
- 유동인구 추이는 2023년부터 연간 합계가 달라졌으므로 2023-01 시작 기간 안에서도 연도 간 비교는 하지 않음
