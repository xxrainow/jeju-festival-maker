- 컬럼: `base_date`, `station_name`, `user_type`, `user_count`
- 정류소명 2,806개, 이용자 유형 9개 (일반, 경로, 청소년, 장애 일반, 장애 동반, 어린이, 유공 일반, 기타, 유공 동반)

  - 처리: 첫 칸은 날짜, 마지막 두 칸은 유형과 인원, 그 사이 전체를 정류소명으로 읽음

  - 처리: 결측 기간은 결과에 표시. 비정상일은 날짜를 직접 고르지 않고 규칙으로 판정
  - 이상일 규칙: 하루 합계가 **같은 달 같은 요일 하루 합계 중앙값의 20% 미만**인 날. 분석에서 기본 제외하고 제외 날짜 목록을 결과와 함께 반환. 기준값(20%)은 조정 가능
  - 20% 기준 결과: 15일 (2020-12-15, 2021-04-10, 2021-12-23, 2022-01-03, 2022-01-25, 2022-07-09, 2022-07-15, 2022-08-11, 2022-12-05, 2022-12-06, 2022-12-28, 2024-06-20, 2024-07-07, 2024-07-08, 2025-03-19). 10%는 15일, 30%는 37일, 50%는 144일

- **같은 정류소의 이름이 시기별로 바뀜.** 예: `제주국제공항4(대정,화순,일주서로)`(~2024-10-06) → `제주국제공항4(대정화순일주서로)`(2024-10-07~). 2019-12-10에도 번호 체계 변경
  - 처리: 공백, 쉼표, 괄호 안 구두점을 제거한 정규화 이름을 따로 만들어 기간 연결

### 2-5. 전국 문화축제 표준데이터 (핵심)

- 1행이 비어 있고 2행이 헤더. `header=1`로 읽어야 함
- 제주 축제 50건 (주소, 주최·주관기관에 제주 또는 서귀포 포함 기준). 좌표 없는 행 2건

- 시기 분포: 3~6월 집중, **11~12월은 개최 축제 거의 없음**. 기존 축제와 겹치지 않는 시기 근거로 활용 가능

## 3. 위치 연결 계획

기준 단위는 **행정동 43개** (센터 4-11과 같은 단위).

| 데이터 | 위치 정보 | 행정동 연결 방법 |
|---|---|---|
| 버스 이용 인원 | 정류소명 | 버스 정류소 기본 정보(API)의 `stationAddress` |
| 와이파이 사용자·사용량 | 장소명 | 공공와이파이 AP 정보(API)의 `addressDong` |
| 관광지 유입자 | 관광지명 | AP 정보에서 같은 이름 찾기, 안 되면 직접 매핑 |
| 관광 숙박업 | 주소 | 주소에서 읍면동 추출 |
| 문화축제 | 주소, 좌표 | 주소에서 읍면동 추출 |

- 리 단위 주소(예: 성산읍 고성리)는 앞의 읍·면으로 묶음
- 시내 법정동(예: 삼도이동)은 행정동 매핑표 필요
- 정류소 기본 정보에서 확인한 문제: 같은 이름 정류소가 다른 동에 있음(예: `(구)삼양검문소` 삼양동/조천읍), 주소가 빈 정류소 있음, 주소 끝 공백 있음
- **연결 후 반드시 매칭률 확인.** 전체 대비 연결 비율과, 연결 안 된 항목이 특정 지역에 몰렸는지 확인
- MVP는 후보 지역 3곳 기준으로 매핑표를 먼저 만들고, 이후 확장

### 3-1. 연결 결과 (2026-11-03, 기간 2023-01 ~ 2025-10)

실행: `uv run python -m analytics.report_area_link`. 결과 표는 `data/processed/area_link_bus.csv`, `area_link_wifi.csv`.

**주소 표기가 데이터마다 다름.**
- 버스 정류소 `stationAddress`는 **행정동** 표기 (`일도2동`, `삼도1동`). 제주시 19개 동, 서귀포시 13개 동, 읍면 10개로 행정동 체계와 맞음
- 와이파이 AP `addressDong`은 **법정동** 표기 (`일도일동`, `도련일동`). 동 지역 62개
- 공식 법정동→행정동 매핑표는 아직 없음. 와이파이 동 지역은 법정동 단위로만 연결하고, 매핑표 확보 후 변환. 결과 표에 `area_level`(행정동/법정동/읍면)로 구분

연결 규칙:
- 같은 이름(정규화 이름 또는 AP 번호 뺀 이름)의 항목이 모두 같은 읍면동이면 **연결**
- 같은 이름인데 읍면동이 둘 이상이면 **애매함**. 추측해서 붙이지 않고 후보 목록만 남김
- 주소가 비었거나 시·읍면동을 읽을 수 없으면 **주소 없음**. 지번이 붙은 주소(`대포동 2309-1`)는 법정동 표기라 동 이름을 쓰지 않음
- 와이파이 버스정류소 장소는 이름 끝 정류소 ID(`[405000250]`, `(406000491)`)로 정류소 주소에 연결 (ID 일치라 추측 아님)
- 주소 없는 정류소는 좌표 최근접 정류소의 지역을 **분포 확인용 참고값**으로만 기록. 연결 결과로 쓰지 않음

| 데이터 | 장소 수 | 연결 (장소 / 이용자) | 애매함 | 주소 없음 | 이름 없음 |
|---|---|---|---|---|---|
| 버스 정류소 | 2,377 | 79.3% / **86.6%** | 2.8% / 7.1% | 11.6% / 2.2% | 6.3% / 4.1% |
| 와이파이 장소 | 1,825 | 77.3% / **81.9%** | 1.0% / 10.0% | 0.1% / 0.0% | 21.6% / 8.1% |

확인한 점:
- 버스 애매함은 **제주시 원도심 동 경계 도로**에 몰림 (일도2동, 이도2동, 건입동, 삼도2동, 용담1동). 길 양쪽 정류소가 서로 다른 동에 속하는 경우. 원도심을 후보지로 볼 경우 이 정류소들의 처리 방법을 따로 정해야 함
- 같은 이름의 서로 다른 정류소가 다른 시에 있는 경우 8곳 (예: 세기아파트 서귀포시 동홍동/제주시 연동). 이용 인원 자료에 이름만 있어 나눌 수 없음
- 미연결의 시 비중은 연결 비중과 비슷함 (시를 알 수 있는 미연결 중 서귀포시 약 33%, 연결 중 서귀포시 29.5%). 한쪽 시에 쏠리지 않음
- 버스 이름 없음은 현재 정류소 목록에 없는 옛 이름 (예: 한국병원, 광양사거리/터미널방면)
- 와이파이 애매함 이용자 비중(10%)의 대부분은 제주동문시장(이도일동/일도일동)과 **올레 코스** (여러 동을 지나는 선형 경로, 미연결 비율 60.8%). 코스는 구간 단위가 아니면 한 동에 붙일 수 없음
- 와이파이 이름 없음은 2022-12-25 AP 목록에 없는 장소 (도서관, 전기차충전소, 번호 공원, ID 없는 옛 형식 버스정류소)

| 여러 동을 지나는 길 (올레·자전거길·숲길) | 와이파이 올레 코스(`N코스`, `N-N코스`, `3-A코스`, `16코스(...)` 형식) 28곳, 제주환상자전거길, 사려니숲길 | 30곳, 7,107,789명 |
| 다른 시에 같은 이름의 정류소 | 버스 애매함 중 후보가 제주시·서귀포시에 걸친 정류소 | 8곳, 504,696명 |

- 다른 시에 같은 이름인 정류소 8곳: 대림아파트, 산양큰엉곶입구, 성판악, 세기아파트, 수산리사무소, 예비군훈련장, 월평마을, 한국통신
- 길 이름이 들어가도 한 읍면동 안에 있는 곳(화순 곶자왈 생태탐방숲길, 녹산로 유채꽃길 등)은 빼지 않음

**후보지 묶음** (`AreaGroup`, `--groups 묶음.json`):
- 후보지를 행정동·읍면 묶음으로 정의. 한 동은 한 묶음에만 들어감
- 연결된 장소는 행정동이 묶음 안에 있으면 그 묶음 (`동 연결`)
- 경계 정류소는 애매함 표시를 그대로 두고, 후보 동이 **모두** 같은 묶음 안에 있을 때만 그 묶음으로 연결 (`경계 묶음`)
- 와이파이 법정동 연결분은 행정동 변환 전까지 묶음에 넣지 않음
- 예시(확정 아님): 원도심 = 일도1·2동, 이도1·2동, 삼도1·2동, 건입동, 용담1동으로 묶으면 버스 경계 정류소 12곳(1,606,313명)이 묶음에 연결됨

### 3-3. 법정동 → 행정동 변환표 (좌표 짝, 2026-11-04)

공공데이터포털 인구 API는 신청하지 않기로 함. 와이파이 AP·정류소의 **법정동 주소**와 **좌표로 판정한 행정동**(3-4 경계)의 짝을 모아 만든다 (`analytics/dong_mapping.py`, 결과 `data/processed/legal_admin_mapping.csv`).

- 짝: AP·정류소 한 대가 짝 하나. AP 1,594대 + 지번 주소 정류소 2곳. 짝이 나온 장소 수(`places`)도 참고로 표시 (한 건물의 AP 여러 대는 짝 여러 개)
- **오류 의심 짝**은 표에 남기고 변환 근거에서 뺌 (사유 기록):
  - 짝 2개 이하인 행정동
  - 다른 시인 행정동 (예: 색달동 → 제주시 애월읍 5개)
  - 법정동이 동인데 읍면으로 판정 (예: 노형동 → 구좌읍 4개)
- 남은 행정동이 하나면 변환, 여럿이면 애매함, 하나도 없으면 근거 부족
- 근거로 쓴 행정동의 짝이 5개 미만(3~4개)이면 **근거 약함**: 변환은 하되 변환표 `evidence`와 숙박업 `conversion`("1:1 변환 (근거 약함)")에서 구분
- 결과: 법정동 62개 중 1:1 45개, 애매함 11개(서귀동, 서홍동, 일도일동, 이도일동, 대포동 등 실제로 걸친 곳), 근거 부족 6개(회천동, 회수동, 도두이동, 월평동, 오라삼동, 외도동)
- 숙박업 동 지역 객실 14,749실 중 행정동 변환: 오류 의심 짝을 빼지 않으면 8,248실, 빼면 **11,992실 (+3,744실)**
- 그중 근거 약함으로 바뀐 숙박업: 15곳 797실 (상예동→예래동 4곳 323실, 하예동→예래동 7곳 238실, 내도동→외도동 4곳 236실)
- 변환하지 못한 숙박업: 여러 행정동 68곳 2,203실, 근거 부족 5곳 491실, 변환표 없음(영남동) 1곳 63실
- 근거 확인 (2026-11-04):
  - 삼양삼동 → 화북동 짝 3개는 모두 한라마을작은도서관 AP 3대 (같은 좌표 33.522203, 126.576501). 삼양동 짝 1개는 18코스 AP (33.526444, 126.57675). 근거 약함
  - 색달동 → 예래동 짝 17개: 중문관광단지 11, 믿거나말거나박물관 2, 중문·색달해변 2, 테디베어뮤지엄 1, 중문관광단지입구 정류소 1. 색달동 → 애월읍 5개는 1100고지 휴게소 (오류 의심)

인구 비율 분할(`build_mapping`, 주민등록 인구 API용)은 코드만 남기고 사용하지 않음. 거주 인구 기준이라 쓰더라도 동 합계 참고용으로만 (2026-11-04 합의).

- 자료: A의 패널 `research/reference/festival_panel_2024_2026.parquet` (3,650행, 2024 1,170 / 2025 1,214 / 2026 1,266). 같은 축제는 `fid`로 이어짐 (1,911개, 같은 fid 안에 같은 연도 중복 없음)
- **2026년만 씀**: 카드 중간값(A의 `tag_budgets`)과 같은 범위. 설계 문서 3절 "중단 축제는 계산하지 않는다"와도 맞음. 축제마다 최근 1건(1,911건)을 쓰면 푸드·디저트 중간값이 2.78억 → 1.8억처럼 카드와 달라져서 쓰지 않음
- **단위**: 패널 `예산`은 백만 원 (A `BUDGET_UNIT_KRW = 1_000_000`). 같은 축제를 B의 2026 계획 로더와 대조해 같은 값 확인 (예: 서울라이트 한강 빛섬축제 2604 = 26억 400만 원). 사용자 입력(원)과 비교할 때 원으로 바꿈
- 예산 결측·0원은 뺌. 방문객은 지자체 신고 값이라 경고를 붙이고, 1인당 비용은 2026년 `계측방법 = 계측`만 씀 (2024·2025년 행은 계측방법이 비어 있음)

| 형식 (2026, 예산 > 0) | 사례 | 하위 25% | 중간값 (카드와 같음) | 계측 1인당 표본 |
|---|---|---|---|---|
| 야간·빛·드론 | 80 | 1.15억 | 3억 | 25 |
| 푸드·디저트 | 45 | 7,000만 | 2.78억 | 15 |
| 영화·책·아트 | 32 | 7,150만 | 2.45억 | 10 |
| 도심·거리·골목 | 31 | 5,000만 | 9,800만 | 13 |
| 맥주·주류 | 28 | 6,775만 | 1.755억 | 5 |
| 여름·물놀이 | 27 | 8,450만 | 1.68억 | 13 |
| 시장·상권 | 27 | 3,250만 | 6,000만 | 6 |
| 정원·가드닝 | 20 | 1.225억 | 2억 | 7 |

- 8개 형식 모두 5건 이상이라 문체부 유형 대체는 지금은 쓰이지 않음 (코드와 테스트는 있음: 형식 태그 사례 5건 미만이면 그 형식 축제에 가장 많은 유형으로 계산하고 evidence `basis`와 경고에 표시)
- 대략 방문객 규모 = 예산 ÷ 계측 1인당 비용(하위 25%~상위 25%). 같은 기준 계측이 5건 미만이면 전체 계측 축제(447건)로 계산

| 상황 | 결과 |
|---|---|
| 예산 입력 없음 | pass, 같은 형식 중간값을 기준 예산으로 제시 |
| 입력 ≥ 중간값 | pass |
| 입력 < 중간값, 입력 이하 같은 형식 사례 있음 | conditional, "소규모 버전" + 사례 최대 3개 (입력에 가까운 것부터) |
| 사례 없음, 카드 scale "기본" | fail, `budget.scale` → "소규모 버전" 제안 + 줄이는 방법 |
| 사례 없음, 카드 scale 이미 "소규모 버전" | conditional + "비슷한 규모 사례 없음" 경고 (루프가 계속 fail하지 않게) |

- 계약의 `budget.scale`은 "기본"/"소규모 버전"뿐이라 "축소"는 "소규모 버전"으로 씀 (계약 변경 없음)
- 출처: "문체부 지역축제 개최계획 2024~2026 (예산은 계획 기준)"

**실데이터 결과** (카드는 A 규칙대로 입력 < 중간값이면 "소규모 버전")
- 시장·상권, 1,000만 원 → conditional. 사례 "제3회 나전역 야시장 야밤바 행사"(강원 정선군, 500만 원, 방문객 500). 대략 900~2,600명 규모
- 푸드·디저트, 1,000만 원 → conditional + "비슷한 규모 사례 없음" (1,000만 원 이하 0건, 하위 25% 7,000만 원). 카드가 "기본"이었다면 fail + "소규모 버전" 제안. 대략 700~5,200명
- 야간·빛·드론, 예산 없음 → pass, 기준 예산 3억 원 (대략 23,800~90,000명)

**형식 태그 오탐**: 축제명 정규식이라 "예술축제"가 맥주·주류("술축제"), "은빛"이 야간·빛·드론("빛")에 걸리는 등 확실한 오탐 9건, 검토 12건. A용 정리: `docs/tag-review-for-a.md`. A 파일은 고치지 않음

## 4. 분석 기본 기간

`analytics/periods.py`에 정의. 기간은 `analysis_period(start_month, end_month)`로 바꿔 쓸 수 있음.

| 용도 | 기본 기간 | 이유 |
|---|---|---|
| 여러 데이터 비교 분석 | 2023-01 ~ 2024-12 | 모든 데이터가 겹치는 기간 (관광지 유입자 2022~2024, 유동인구 ~2025-04) |
| 단일 데이터 후보지 분석 | 2023-01 ~ 2025-10 | 2022년 버스 이상일 판정 불안정 구간(2022-08, 2022-11) 제외 |
| 최근 패턴 확인 | 2025-01 ~ 2025-10 | 비교 분석과 섞지 않고 따로 표시 |

- 버스 이상일 규칙(20%)은 그대로 유지. 2023년 이후 기간에는 판정이 불안정한 달이 없음
- 유동인구 추이는 2023년부터 연간 합계가 달라졌으므로 2023-01 시작 기간 안에서도 연도 간 비교는 하지 않음
